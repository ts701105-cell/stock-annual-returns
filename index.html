逐年報酬試算

輸入股票代號與投入日期，算出從投入那天起每一個年度的報酬率、累積報酬與年化報酬。

輸入代號後按「抓價並計算」，會用你的 Twelve Data API 金鑰自動抓歷史股價。
Twelve Data API 金鑰

各年度報酬率 （紅漲綠跌）

計算方式：以投入日當天（遇假日則取下一個交易日）的收盤價買進。第一年從投入日算到該年最後交易日；之後每年以前一年最後收盤價對當年最後收盤價；最新一年算到資料最後一天。

「總報酬」會把每次除息的股利，以除息前一日收盤價再投入；股價已做分割調整。美股與美國 ETF 透過 Twelve Data API 自動取得；台股在 Twelve Data 需付費方案，免費方案請用下方手動匯入。

手動匯入時，「總報酬」採用資料中的 Adj Close 欄位；資料沒有這一欄時會改用收盤價。支援格式：Yahoo Finance 下載的 CSV、證交所／櫃買中心下載的 CSV（民國日期會自動轉換），或任何含「日期」與「收盤價」欄位的表格。
